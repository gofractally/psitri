# psitri

Persistent, transactional key-value engines (static ART, ART-on-sal, legacy
btree, composed delta pipelines) sharing one abstract database concept (adb),
one behavioral test battery, and one benchmark suite.

Migrated from the psitri-merge working repo at tag `reorg-baseline`; the
structure, rename map and carried TODO ledger are in `docs/reorg_plan.md`.

# Common bank comparison

The maintained benchmark uses one workload across the Small Engine, Large Engine,
MDBX, RocksDB, SQLite, and DuckDB.

See the [build instructions and comparison protocol](../../website/content/fair-comparison.md)
for dependencies, correctness checks, durability cohorts, retained evidence,
performance runs, and the scope of the measurements.

Run `python3 scripts/fair_bank.py --help` from the repository root.
